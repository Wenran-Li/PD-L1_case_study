AILSCI 100191 — Supplementary reporting templates

This package contains five files: four machine-readable templates and this README.

- reporting_checklist.yaml and reporting_checklist.csv: reusable minimum-reporting checklist derived from Table 6 of the accepted manuscript, including the reporting item, tier, and full description of what should be reported.
- design_card.yaml: reusable design-card template following Appendix A, Listing 1.
- design_card.csv: long-form CSV representation of the design-card fields (section, field, value). The long-form layout represents YAML's nested groups in a flat CSV table.

These files are BLANK reporting templates, not observed candidate data or experimental results. YAML null values and empty CSV cells are intentionally left blank for users to complete when documenting their own designs or studies. No missing value should be interpreted as a measured zero or a negative experimental result.
